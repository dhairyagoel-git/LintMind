# LintMind 🚀

LintMind is an AI-powered code review platform that analyzes code quality, detects bugs, suggests optimizations, and generates production-level improvements using Large Language Models (LLMs).

Built with React, Monaco Editor, Node.js, Express, and Groq API.

---

# ✨ Features

* 🧠 AI-powered code reviews
* ⚡ Production-level improvement suggestions
* 🔍 Bug and issue detection
* 📈 Complexity analysis
* 🛠 Diff-based code improvements
* 💻 Monaco Editor integration
* 🌙 Modern developer-friendly UI
* 📦 Markdown-based review rendering
* 🔥 Syntax highlighted code blocks

---

# ⚙️ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/dhairyagoel-git/LintMind.git
```

---

## 2. Setup Backend

```bash
cd backend
npm install
```

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key_here
```

Start backend server:

```bash
npm run dev
```

---

## 3. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```
